# GamePilot — Test Client Prototype (v0.2)

Видимый прототип автоматизации для собственного тестового Windows-клиента.

## Что добавлено в v0.2
- Несколько точек в одном сценарии: можно добавлять, переименовывать, удалять и переставлять точки.
- Для каждой точки сохраняются координаты, число кликов и индивидуальное ожидание после клика.
- Цикл проходит точки по порядку, затем повторяет последовательность заданное число раз.
- Журнал событий сохраняется в `%USERPROFILE%\\GamePilotTestClient\\gamepilot.log`.
- Совместимость со старым профилем, в котором была только одна точка (`point`, `clicks`, `gather_wait`).
- Аварийная остановка кнопкой; также включён стандартный PyAutoGUI failsafe (перемести курсор в левый верхний угол основного экрана).

## Установка в Windows
```powershell
py -m venv .venv
.venv\\Scripts\\activate
py -m pip install -r requirements.txt
py main.py
```

## Использование
1. Открой собственный тестовый клиент и размести нужные объекты на экране.
2. В GamePilot нажми «Добавить точку со снимка экрана» и щёлкни по объекту.
3. Введи название точки. Добавь остальные точки и при необходимости измени их порядок.
4. Задай количество циклов и паузу между циклами.
5. Подтверди, что это твой тестовый клиент, затем нажми «Запустить сценарий».
6. За 2 секунды переключись в тестовый клиент. Для остановки нажми кнопку аварийной остановки в GamePilot.

## Ограничения этой версии
- Координаты абсолютные относительно основного рабочего стола, а не привязанные к окну. Если окно переместить, изменить разрешение или масштаб интерфейса, точки нужно выбрать заново.
- Точки выбираются на полном снимке экрана; проверяй координаты перед запуском.
- Ввод выполняется обычными видимыми кликами мыши. Нет распознавания состояния игры, чтения памяти процесса, внедрения кода, скрытия или обхода античита.
- Тестируй только в собственной среде и в соответствии с её правилами.

## Проверка профилей
Из корня папки проекта выполни:
```powershell
py -m unittest discover -s tests -v
```
Тесты проверяют миграцию старого профиля, загрузку нескольких точек, ограничение значений и отклонение отрицательных координат.
