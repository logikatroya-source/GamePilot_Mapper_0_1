# Результаты проверки редакции 0.1

## Исправлено
- Профиль больше не перезаписывается молча при повторном создании с тем же именем.
- Имя профиля очищается от опасных символов и Windows-зарезервированных имён.
- JSON сохраняется атомарно через временный файл и `os.replace`.
- История снимков ограничена 500 записями; журнал интерфейса также ограничен.
- Детектор проверяет входные данные, нормализует результаты OpenCV, применяет локальные максимумы и IoU-подавление повторных рамок.
- Трекер использует LK optical flow + RANSAC affine estimation и проверяет валидность кадров.
- Снимок экрана делается после временного скрытия окна приложения, чтобы UI не попадал в захватываемый кадр.
- Добавлены открытие профилей, настройка порога детектора и обработка ошибок в интерфейсе.

## Проверки, выполненные в среде разработки
- 8 unit-тестов прошли успешно.
- Синтаксическая компиляция всех 10 Python-файлов прошла без ошибок.
- ZIP исходного проекта прочитан без ошибок CRC.
- Проверен поиск шаблона на синтетическом кадре и выполнен пробный прогон на одном предоставленном примере.

## Что не удалось проверить здесь
- Полноценный запуск окна Windows: в среде проверки отсутствуют PySide6 и рабочий графический дисплей.
- Реальный захват рабочего стола на Windows.
- Сборку EXE через PyInstaller.
- Точность распознавания на разных сценах и масштабах тестового клиента.

## Известные функциональные ограничения
- Результаты template matching — только кандидаты; возможны ложные срабатывания.
- Пиксельный сдвиг между кадрами не является точной мировой координатой.
- OCR имени ресурса, классификация зачарования, распознавание препятствий и построение полноценной карты ещё не реализованы.
