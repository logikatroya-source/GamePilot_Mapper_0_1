# GamePilot Mapper 0.1 — проверенная редакция

Визуальный исследователь экрана для собственного тестового клиента. Приложение работает в режиме наблюдения: не управляет персонажем, не отправляет игровые команды, не читает память процесса и не внедряется в клиент.

## Возможности
- ручной и периодический захват рабочего стола;
- окно приложения временно скрывается перед снимком, чтобы не попадать в собственный кадр;
- экспериментальный многомасштабный поиск шаблона «Грубый камень T1»;
- настройка порога совпадения и визуальная разметка кандидатов;
- локальные JSON-профили: создание, открытие и защита от случайной перезаписи;
- атомарное сохранение профиля и ограничение истории наблюдений;
- экспериментальная оценка сдвига изображения между кадрами;
- журнал с ограничением числа строк.

## Ограничения
Это не полноценная карта игрового мира и не SLAM. Сдвиг пикселей не равен точному перемещению персонажа: камера, анимации, эффекты, масштаб и перспектива могут влиять на оценку. Координаты карты условные. Детектор выдаёт кандидатов, а не подтверждает ресурс. OCR надписи «Грубый камень», обнаружение зачарования и распознавание проходимости пока не реализованы.

## Установка Windows
Рекомендуется Python 3.11 или 3.12 (64-bit). В PowerShell из папки проекта:

```powershell
py -3.11 -m venv .venv
.venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

Если PowerShell запрещает активацию окружения, можно запускать напрямую:
```powershell
.venv\\Scripts\\python.exe -m pip install -r requirements.txt
.venv\\Scripts\\python.exe main.py
```

## Проверка тестов
```powershell
python -m unittest discover -s tests -v
python -m py_compile main.py vision\\resource_detector.py core\\location_store.py mapping\\landmark_tracker.py
```

## Сборка EXE
```powershell
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name GamePilotMapper --collect-all PySide6 --collect-all pyautogui --collect-all cv2 --add-data "assets;assets" main.py
```
Готовый EXE будет в `dist\\GamePilotMapper.exe`.

## Данные
Профили сохраняются отдельно от исходников в `%USERPROFILE%\\GamePilotMapper\\Locations`. Для резервной копии достаточно скопировать эту папку.

## Примечание
Шаблон T1 и примеры изображений сохранены в `assets`. Каталог `legacy_v0_2` оставлен без изменений как архив прежнего прототипа.
